# 3D Fashion Avatar Website

Open `index.html` in a modern browser.

## Included
- Interactive Three.js 3D avatar
- Orbit controls: drag to rotate, wheel/pinch to zoom
- 10 outfit presets
- Auto rotation, floor grid, random look
- Responsive mobile/desktop layout
- Optional `.glb` / `.gltf` loading

## Important
The supplied photograph is included as `reference.png`. A photograph alone does not contain the mesh, rig, materials, hair geometry, or texture maps needed for a truly photorealistic 3D human.

For a genuinely close 3D likeness, create/export a rigged GLB from a photogrammetry or avatar-generation workflow, then use **Load GLB**. The viewer is already structured for that workflow.

The current default avatar is a lightweight procedural 3D fashion mannequin so the website works immediately without a large model file.
